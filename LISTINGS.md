# Kito Oak Haven — listing submissions

Paste these fields **exactly the same way every time**. Consistent name, address
and phone across listings is the whole mechanism; a listing that says "Kito Oak
Haven Apartments" or uses a different number works against the ones that don't.

Honest expectation: individual directory backlinks are low value, and some of
these sites are thin. The reason to do it is referral traffic from people
searching in Kenya, plus consistency. It is not a ranking trick.

## Rules

**Never pay for a listing.** Every one above has a free tier. Paid directory
placement does not produce bookings at this scale.

**Never submit to anything that asks for a password you use elsewhere,** or for
ID documents. A directory needs a name, an address, a phone and a URL.

**Keep a record.** Add a row to the Kito Bookings sheet, or a note here, for
each site: date submitted, whether it went live, and whether the entry can be
edited later. Chasing an unlisted submission six weeks on is otherwise
impossible.

**One a day is fine.** Submitting to five directories in an hour from one IP
looks like exactly what it is.
