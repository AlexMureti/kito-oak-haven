# Booking system page — storyboard

Written before the code, per OPEN-LOOPS line 49: *do not resume Kito by editing
code.* The first version of this page was built straight into a palette I
invented. It was competent and it was off-brand, which for a page whose whole
job is to look like a system worth trusting is the same as being wrong.

---

## The job

**Reader:** the owner. Not technical. On a phone. Deciding one thing — whether
the person running her website can be trusted with bookings.

**The page's single job:** make her *feel* the collision problem being solved,
then ask for the one thing that turns it on.

**What it is not:** documentation. She will not read a manual. She will press
something, watch it answer, and form a judgement in about eleven seconds.

---

## What the logo gives us

The mark is a fluted classical column forming the stem of a K, its leg sweeping
into an arch, an acorn set in the crook. Struck gold foil — highlights and
shadow, never a flat fill. The wordmark is wide-tracked serif caps split by a
small lozenge.

Four things transfer, and everything on the page comes from one of them:

| From the mark | Used as |
|---|---|
| **The fluting** — vertical grooves, evenly spaced | Each day cell is a flute: arched head, groove down the middle, filled to the top when booked. |
| **The arch** in the K's leg | The soft crown on each night, and on the working plate. Restrained — a curve, not a doorway. |
| **The acorn** — one precise jewel at a junction | A single gold lozenge marking the arrival night. One per view, never decoration. |
| **Foil, not paint** | Gold is only ever a gradient that catches light. A flat gold fill is the tell that nobody looked at the logo. |

## Colour carries meaning, not decoration

The four states are the brand's own palette, and the assignment is an argument:

- **Free** — cream. An open bay in the colonnade.
- **Her Airbnb** — pine. Her existing channel: established, solid, already there.
- **A website booking** — **gold.** The revenue this system exists to create.
  She should want to see gold appear.
- **Collision** — terracotta. The brand's one warm accent, and the only alarm
  colour it owns. Not a generic red.

Gold for direct bookings is the persuasive move on the page. Nothing has to
argue that website bookings are valuable if they are literally the gold ones.

## One visual world

Pine ground, cream working plate, gold instrument. No light-mode variant —
the brand *is* pine and gold, and a cream-mode version would be a different
company. Every colour is painted explicitly so the page holds on any host
background. This is a decision, not an omission.

## The beats

**1 — The plate.** Pine ground. The gold lockup at rest, a hairline gold rule
with the lozenge, then one Cormorant line: *Two calendars sell one apartment.*
The foil gradient drifts slowly, as if catching light. That is the only ambient
motion on the page.

**2 — The calendar.** The instrument, on a cream plate. A real month grid with
arrows, a year of horizon, and days drawn as flutes.

This started as a single row of twenty nights, which was wrong and had to be
rebuilt. Twenty nights is not a booking calendar — a guest asking for dates two
months out could not even see them, which made the whole thing a toy. The
metaphor was driving the layout instead of the function. A facade carries ranks
of columns rather than one row of twenty, so the grid is closer to the mark
anyway, and it fixes the phone at the same time: seven columns give ~39px cells
where twenty flutes gave ~12px.

**3 — The verdict.** Not a coloured alert box. A gold rule, one Cormorant word
(*Available* / *Collision*), then the reasoning in Inter naming the actual
nights. **When it collides it does not stop at no — it offers the nearest free
window that fits.** That single behaviour is the difference between a checker
and a system, and it is what will make her think this person has done it before.

**4 — The one thing she does.** Three steps, only the first of which is work,
and it takes thirty seconds. Numbered because it genuinely is a sequence.

**5 — The rules it follows.** Four decisions that show judgment: an enquiry
does not hold a night; a calendar that fails to load is a failure, not an empty
calendar; nothing is deleted; every run is written down. This is where the page
earns the word *intelligent* — not by claiming it, by showing what it refuses
to do.

**6 — The limits.** What it cannot see. Stated plainly, because a system that
names its own blind spot is the one you trust with the rest.

---

## Laws for this page

1. **No flat gold.** Every gold surface carries the metal gradient.
2. **One accent moment per screen.** Terracotta only ever appears on an actual
   collision. If she never causes one, she never sees it.
3. **She never types a date.** Presets first, pickers second.
4. **No sentence explains what the strip already shows.** If the visual works,
   the caption comes out.
5. **The example is labelled an example.** Every time. It is not her data and
   must never be mistaken for it.

## Deliberately absent

No dashboard chrome, no fake metrics, no logos of tools, no screenshots of the
spreadsheet. The page shows the mechanism working, not pictures of software.
